## Substantive composition checks

1. **No independent desired global output premise in the closed tick.** `UniformActualCompleteClockTick.execution` obtains actual finite-axis output `a`, its `printed` and `atReady` fields, then passes that same `a` into `UniformProducedClockTickTracked.execution`. Numeric prefix transport uses the retained source cells from the same axis execution; the final `axes.trans kernel` is not a join of unrelated states. `UniformActualCompleteClockExecution.execution` iterates this output invariant and includes the false branch/halt through `UniformActualClockRealInduction.clocks`.
2. **The conditional child helper is actually specialized.** `UniformGlobalKernelDiagonalRetention.execution` has a `RootBody` premise. That alone is not a closed algorithm. The actual path is `UniformProducedClockTick.execution` → `UniformActualGlobalTickContext.execution` → `UniformGlobalClockTickExecution.execution` → `UniformActualTickRetention.execution` (`lean/UniformActualTickRetention.lean:13`). The last passes `UniformActualSectorRootBody.root_body` (`lean/UniformActualSectorRootBody.lean:13`), which invokes `UniformRecursiveRootExecution.execution` with the actual grouped source and header. This closes the root execution premise at the inspected boundary. The recursive proof itself is assigned to the finite/recursion audit.
3. **Actual cells, not default values, establish the next source.** `UniformProducedClockTick.execution` obtains `Option.map Scalar.value = some ...` for the real heap cells; `UniformExecutedTaggedBank.present/value` then produce source presence and values. `UniformActualClockNumericInvariant.step` (`lean/UniformActualClockNumericInvariant.lean:31`) relates the old actual source to the existing prefix, rather than introducing fresh tagged values to continue the loop.
4. **Prepared tags share actual execution.** The prepared specialization runs `UniformActualTickRetention.execution` and proves tags for that run through `UniformActualKernelPreparedTags.of_execution`. The supporting `UniformPreparedKernelAnyExecution.execution` uses determinism to identify its tag-producing initialized-kernel run with the supplied literal numeric run. This is proof composition, not an additional runtime tag or complex-zero decision. Lower prepared-tag theorem internals are not fully audited here.
5. **Cost is a consequence of geometry.** `UniformCanonicalClockStepCost.actual_step_bound` (`lean/UniformCanonicalClockStepCost.lean:36`) bounds actual per-axis costs plus actual produced-kernel budget using sector geometry and the selected kernel bound. `envelope_eq` at line 84 folds the real allowance over the complete horizon. The clock output count and cheapness belong to the same composed run. Independent verification of the exact exponent and asymptotic final envelope lies outside this synchronization audit.
6. **Physical Fourier order remains intermediate.** `UniformPhysicalSynchronizedSchedule.product` produces the tensor Fourier matrix in the fixed physical MSB order. The paper’s one-dimensional positive DFT requires the separately charged alpha input and beta inverse output corrections. `UniformMasterSynchronizedLayers` is a separate algebraic bridge; citing it alone does not establish that the literal clock uses its master-root DAG or executes CRT permutations.

## Findings and limitations

- **No confirmed blocker in inspected synchronization/clock boundaries.** The checked tensor multiplication order, sector packing formula, singleton removal, physical child bit order, actual-state joins and internal RootBody specialization agree with the cited paper arguments.
- **Coverage limitation, not a proved defect:** the complete-clock theorem still accepts entry/source/cache conditions. This audit establishes how it closes local per-tick Action/child premises, not that the final all-length caller initializes every condition. The final caller, root semantics and preparation execution require independent review.
- **Documentation distinction:** matrix identities, directory geometry/counts, actual execution and asymptotic cost are different obligations. Comments now state which is proved at each mapped boundary. The generic conditional helpers and auxiliary master-root schedule must not be reported as standalone completion of the uniform theorem.
- **Paper implementation variation:** explicit RAM offsets, stacks, heap regions, dependency tags, produced calendar adapters and the common kernel-plus-diagonal consumer have no literal one-to-one paper lemma. Their comments cite the surrounding argument and call them bookkeeping. Correctness depends on their execution/retention theorems, not a claim that the PDF specifies those offsets.
