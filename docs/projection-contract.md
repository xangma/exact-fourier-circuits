# Exact projection of the full framed network

`projection.py` makes a manageable algebraic quotient of the complete network.
It preserves its scalar shears, directional operations, arbitrary auxiliary
data, terminal corrections, padding transforms, and final role-axis layers.
It does not produce or execute the astronomical saving word, and the small
`h=4` source network has no positive call saving.

## Algebraic contract

Let `L:F2^(m*f)->F2^k` be surjective. Its columns are the integer masks
`images[j]=L(e_j)`. For a reduced array `g`, the pullback is `f(x)=g(Lx)`.
Translation obeys

```
R_z (g composed with L) = (R_(Lz) g) composed with L.
```

Therefore `C_z=a I+b R_z` restricts to `C_(Lz)`. Pointwise scalar gates commute
with pullback as well. The full projected program has exactly the restriction
of the original framed network to this invariant subspace. The projection is
proved surjective by an explicit identity minor in its first `k` columns;
remaining columns are generated by `Random(seed)`.

Each original directional instruction with `f` columns emits **one record per
column**. Its mask is

```
mask_c = XOR(images[c*m+j] for j in support(z)).
```

The product `C_mask_0 ... C_mask_(f-1)` must not be replaced by a single
`C_(XOR masks)`. In contrast, terminal translations may be combined by XOR
because `R_u R_v=R_(u+v)`. A zero directional mask is retained as an identity
record; the evaluator does not try to call C on two equal coordinates.

The independent final target on the address field is the product of the
`m*f` projected ordinary unit-axis kernels `C_images[j]`. In the Walsh basis
its multiplier at frequency `nu` is

```
i ^ sum_j parity(images[j] AND nu).
```

`projected_target_exact` computes that multiplier independently of the framed
network, using exact Walsh transforms and Gaussian rational arithmetic. When
padding is included, it then applies the final C transform on every role bit.

## Program and coordinate layout

Build a program with

```
build_projected_program(h=4, bits=6, columns=1, seed=130, include_padding=True)
```

The result has `records`, `checkpoints`, `metadata`, and `.to_dict()`. The JSON
schema is `exact-fourier-projected-program/v1`; top-level fields are `schema`,
`projection`, `metadata`, `records`, and `checkpoints`.

Every record is `[op,target,arg,numerator,denominator,inverse]`:

| op | Meaning |
|---:|---|
| 0 | Apply directional `C_arg` to role `target`; `inverse` adds the translation after the forward call. Zero mask is identity. |
| 1 | For every address, add `(numerator/denominator)` times role `arg` to role `target`. |
| 2 | For bank pair `X=target,Y=arg`, set `new X=old Y`, `new Y=-old X`. |
| 3 | Translate addresses in role `target` by XOR mask `arg`. |
| 4 | Apply C to all role-index pairs `(r,r XOR arg)` with `r AND arg=0`, at every address. `target` is unused. |

Unused rational fields are `0,1`; unused inverse flags are false. Records with
zero masks remain present. All pointwise shear coefficients are nonzero.

Full coordinates use the role as the high field and reduced address as the
low field: `index=(role << address_bits)|address`. Original column `c` occupies
bits `c*m` through `(c+1)*m-1`. Sparse binary tensor indices use row-major
flattening inside a column. A projected directional pair uses the lowest
supported bit of its mask as the pivot; this chooses each pair once.

The default original network has 944 roles: X roles `0..63`, Y roles `64..127`,
and dirty auxiliary roles `128..943`. It pads to 1024 roles, including arbitrary
data in roles `944..1023`, and applies ten role-axis layers. Its projected
address width is 64, so the total state has 65,536 complex coordinates. The
program has 72,842 records, including 62,208 source directions, 5,376 source
shears, 128 terminal records, 5,120 padding directions, and ten role layers.
These are macro counts, not forward-C-call counts or scalar gate counts.

Checkpoints are objects `{label,record_index}` and capture the state **after**
records `[0:record_index]`. Their labels are `stage_1`, `stage_2`, `stage_3`,
`terminal_translation`, `terminal_bank_exchange`, `padding`, and `role_axes`.
The last two occur only when padding is included. Stage boundaries precede
every operation from the next source stage; they are recovered from the
separate auxiliary-role ranges of the original invocations.

## Exact evaluation and verification

`evaluate_projected_exact` accepts nested exact values shaped `(roles,width)`.
With `compiled_shears=True`, it executes the three forward C calls and every
monomial scaling from `words.shear_steps`. This temporarily changes the source
role as the word requires, then restores it exactly. With false, it uses the
net shear as an economical independent comparison. Checkpoint snapshots are
optional. State and operation limits are checked before allocating large
arrays; the enormous saving seed cannot enter this evaluator accidentally.

The focused tests establish the local intertwining identity on **every**
reduced basis vector for a surjective three-to-two-bit map, for all odd source
directions, both inverse choices, and the complete source tensor target. This
is a full matrix check on that bounded invariant subspace, including a source
direction that projects to zero.

Whole-network tests execute all roles with arbitrary dyadic complex data:
the padded one-bit projection uses the actual three-C shear compilation and
all checkpoints; the unpadded two-bit projection and padded two-column
projection also agree exactly with the independent Walsh target. These tests
verify particular full-network inputs. General equality of the projected
program follows from the algebraic intertwining identity and the source
network identities, rather than from claiming sampled inputs exhaust its
matrix.

## Floating-point interpretation

This quotient is an exact algebraic reduction. It has fewer physical
coordinates, can turn directions into identities, and can change pair
orientation. Its C and shear implementations also choose concrete arithmetic
orderings. A floating-point execution consequently measures the numerical
stability of this reduced program and the chosen scalar kernels. It does not
reproduce every rounding operation of the astronomical original word, prove
stability at its full width, demonstrate a saving, or verify a Lean witness.

Within a compiled shear, monomial scalings can involve denominators 3 and 5.
Although record-boundary results are dyadic for dyadic input and this rational
network, compiled-word intermediates need general rational arithmetic. A
dyadic checkpoint oracle should use the exact net shear and compare only at
record boundaries; it must not label the internal compiled word dyadic.
