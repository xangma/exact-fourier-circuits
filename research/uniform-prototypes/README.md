# Follow-on prototypes

These byte-identical snapshots preserve the agents' next-step work. They are
outside `lean/UNIFORM_CHECKS.json`, normal Lake libraries and aggregate
certification. The manifest records their hashes and original scratch paths.
They do not prove the complete uniform algorithm.

| Source | Checked boundary | Remaining work |
|---|---|---|
| `UniformFixedNetworkShearChildMachine.lean` | Default standalone Lean compile, 200 permitted axiom closures, 900 exact cases and five guard controls. Actual fixed40 scalar child; cost `10*V+code+18`, exact flags/frames, actual macro-field bridge. It executes prepared scalar arithmetic; numeric agreement with the three-C word does not certify execution or a C-call count for that word. | Continuous opcode dispatch/return and charged base/volume setup. |
| `UniformEmptyStartupMatchingPreparation.lean` | Default standalone Lean compile, with linter warnings. Explicit selected axis193 under `ell n >= 194`; radix capacity and complete workspace geometry fit `(n+2)^19`. No normal-library build, axiom census or execution fixtures. | Charged header initialization, actual operand input bank, continuous1460-to2669 startup and smaller-radix fallback. |
| `UniformSixCDepthColorController.lean` | Default focused compile against normal libraries, 46 permitted axiom closures, 1232 exact cases and six controls. Continuous fixed796 forward body derives matching/packing geometry and executes the real six-C loop in at most `4*K+596*r+155` steps. Ordinary current-depth table/color/layout and generic prepared banks remain entry inputs. | Outer depth/color cursor, inverse body, true/false regeneration, both broadcasts and full six-phase action/restoration. |

From the repository's `lean/` directory, inspect either source with:

```sh
lake env lean ../research/uniform-prototypes/UniformFixedNetworkShearChildMachine.lean
lake env lean ../research/uniform-prototypes/UniformEmptyStartupMatchingPreparation.lean
lake env lean ../research/uniform-prototypes/UniformSixCDepthColorController.lean
```

The scalar-child receipt and handoff retain their original log paths. Those logs
are local diagnostics; the copied source hashes match the checked originals.
